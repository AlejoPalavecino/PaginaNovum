# Fuentes

No se incluyen archivos binarios de fuentes en este paquete.

## Tipografía de marca
- **Títulos:** Helios Extended.
- **Texto, navegación, botones e interfaz:** Inter.

## Implementación
1. Obtener **Helios Extended** desde la fuente/licencia autorizada por la marca y generar/usar la versión web permitida por esa licencia.
2. Instalar **Inter** desde una fuente oficial o mediante el gestor de paquetes/CDN aprobado para el proyecto.
3. Mientras Helios Extended no esté disponible en el entorno de desarrollo, usar una fallback temporal sin deformar ni condensar artificialmente otra fuente.

### Variables CSS sugeridas
```css
:root {
  --font-display: "Helios Extended", "Arial Narrow", Arial, sans-serif;
  --font-body: "Inter", system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
}
```
