- `seccion05-icono_entrega.png` — icono para etapa 05 Entregamos.
- `seccion05-nodo_hud_naranja.png` — nodo decorativo para los puntos de avance de la línea vertical.

La línea vertical naranja, los conectores horizontales, círculos numerados, bordes y microdetalles se recomienda construirlos en CSS/SVG para que puedan animarse con el scroll y mantenerse nítidos en cualquier resolución.
